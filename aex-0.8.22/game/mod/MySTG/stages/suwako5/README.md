## 七石七木起点与手长足长激光位置修正

本次仅对TH10 card2/card6启用原生type0线激光的长度/起点逻辑：ECL第5个参数是初始长度（这两张均为0），第6个参数为最大长度（128/320），不是出生时立即绘制的完整长度。原生0x41D4CF先按源速度增长长度，达到最大长度后才移动尾端。七石七木的7个源发射点均在y=0，第一轮script tick91发射，前40个更新由0长到320，尾端固定在顶端；随后才按原速度变换移动。

手长足长的原生反弹0x41CFD0检查激光前端，从越界前端接出初始长度0的反射段，入射段保持原方向离场；反射模板的剩余次数在激活时消耗，复制给新段后不会多反弹一次。旧实现把整根激光按普通弹翻向，造成画面下方短白束突然折入的异常。可复现候选：第一轮约2.3秒、旧tick138在左右边缘附近反弹；修正前截图`fix06-before-card2.jpg`中左下/右下斜向内的短白束。用户描述未明确到唯一束，不能据此断言一定是用户指的那一道。
