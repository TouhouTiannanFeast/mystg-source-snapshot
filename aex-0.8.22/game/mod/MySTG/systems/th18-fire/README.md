# 虹龙洞灵梦火力适配

数据取自零售版 TH18 v1.00a 的 `pl00.sht`，文件哈希保存在 `data.lua`。当前启动器使用灵梦，内部灵力仍固定400，HUD仍隐藏。

- 本体弹每3帧两发，每发14伤害；高速4个追踪弹每发20伤害，使用120帧计时器上的模7判定；低速8针每3帧齐射，伤害依次为7/7/8/8/8/8/7/7。
- 短/长计时器分别循环0–14与0–119；松开射击后短周期完成才停止发弹。子机位置、发射角、速度、矩形尺寸来自SHT；追踪距离256、前60帧转向比例0.08和加减速来自原程序。
- 所有本模块伤害源合计，每敌每帧上限90。敌机既有无敌和Boss伤害倍率继续生效。上次报告的高速约1246伤害/秒是忽略120帧回绕的估算；完整120帧发射原始伤害2560，即1280/秒，实际扣血仍受命中和上限影响。
- Bomb高速/低速均使用8个灵球：半径56的伤害区，每3帧伤害15，累计原始伤害达到400后爆炸；爆炸伤害100、持续11帧、半径64起每帧增加8。200帧时强制引爆。无强化卡版本；没有恢复原作强化Bomb卡。
- 当前沿用项目已有射击和Bomb贴图；没有移植原版命中特效ANM。Bomb追踪、绕行与爆炸使用上述原生数据，但敌人碰撞使用项目现有碰撞盒，未声称整套Bomb动画和原作逐像素一致。库存扣除、既有低速/高速冷却240/300、无敌360保持原项目数值。
