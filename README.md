# 用于2026秋tny的超级拼装STG

这是东方天南宴关于东方Project主题修改版stg项目的重要源码，使用LuaSTG aex+ v0.8.22引擎开发，框架采用 THlib 。
我们的项目有很多名字，但最后也其实没定好。包括但不限于：东方风魔录、东方风神京、FX战士月夜见……

## 内容

- 包括所有已开发的符卡（当然，有多少要取决于项目的进度）及其他独立实验模组。
- scripts/ 下的准备工具、局部验证脚本和 SHA-256 文件清单 SOURCE_MANIFEST.json。
- 项目 release 内是解压即玩的成品。不需要额外安装 LuaSTG 引擎。

## 使用条件

仓库的源码存档仍旧是依赖LuaSTG的。如果要进行项目开发，需要自行准备 LuaSTG AEX+ v0.8.22 及相应资源，按目录结构放入 aex-0.8.22/game；

项目仅供参考。模组资源不随本快照提供，部分脚本还依赖本地的研究资料。缺少这些依赖时，模组和验证脚本不能独立运行。

请自行通过 LuaSTG 加载对应模组。注意，scripts/ 下部分验证脚本保留 G:\MySTG 的本地路径。
